# Premier League Players — Position Classifier

Учебный проект по машинному обучению. Задача — предсказать позицию футболиста в Премьер-лиге по его защитной и прессинговой статистике.

## Данные

Файл `PL_Players.csv` — статистика игроков АПЛ. Используются только оборонительные метрики (единоборства, прессинг, блоки, перехваты, подборы), потому что именно они лучше всего разделяют позиции.

| Признак | Описание |
|---|---|
| 90s | Количество проведённых полных матчей (минуты / 90) |
| Tkl | Количество единоборств |
| TklW | Выигранные единоборства |
| Press | Количество давлений на соперника |
| Succ | Успешный прессинг |
| Blocks | Заблокированные мячи |
| Pass | Заблокированные передачи |
| Int | Перехваты |
| Tkl+Int | Единоборства + перехваты |
| Clr | Выносы |

## Что делает код

### Part I — Многоклассовая классификация

Задача: определить позицию игрока (DF, MF, FW и т.д.) по статистике.

1. Смотрим баланс классов
2. Делим данные: **70% train / 15% val / 15% test** (с stratify)
3. Подбираем гиперпараметры **Decision Tree** через GridSearchCV (глубина, min_samples, критерий)
4. Оцениваем по **Macro F1** — он честнее accuracy на несбалансированных классах
5. Сравниваем с **KNN (n=8)** в pipeline со StandardScaler

### Part II — Бинарная классификация + ROC

Задача: отличить нападающих (FW) от полузащитников (MF).

1. Фильтруем датасет, оставляем только FW и MF
2. Делим 80/20
3. Обучаем **Logistic Regression** (с `class_weight="balanced"` из-за дисбаланса классов)
4. Строим **ROC-кривую** и считаем **AUC**
5. Сравниваем метрики при разных порогах классификации: 0.3 / 0.4 / 0.5 / 0.6 / 0.7
